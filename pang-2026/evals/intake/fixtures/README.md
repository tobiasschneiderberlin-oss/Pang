# PANG — intake eval fixtures

Drop an image + a matching JSON declaration here, register it in
`../fixtures.ts`, and the runner picks it up.

## Adding a fixture

1. **Image.** PNG or JPEG, under 4 MB (Vercel body limit is 4.5 MB
   and we need headroom). Prefer public-domain works — each fixture's
   source + license must be recorded in this README.
2. **Registration.** Add an entry to `../fixtures.ts`. Declare only
   the fields you want the scorer to grade.
3. **Run.** `npm run eval:intake:mock` locally to smoke-test
   scaffolding; `ANTHROPIC_API_KEY=… npm run eval:intake` to hit
   the real model.
